# Architecture Decision Records

Architecture Decision Records capture important technical decisions and their rationale.

Use ADRs for decisions such as:

- execution backend design;
- state memory layout;
- grid connectivity;
- case-specific compilation;
- DG storage;
- dependency adoption;
- MPI ownership/communication strategy;
- native data format.

## Status values

Recommended:

- Proposed
- Accepted
- Superseded
- Rejected

## Naming

```text
0001-short-decision-name.md
0002-another-decision.md
```

Do not renumber existing ADRs.

## Template

Copy `0000-template.md`.
